# TfcIcons

The HMI's own glyph font, `assets/fonts/TfcIcons.ttf`. Material and Font
Awesome cover the user interface; this covers the plant — motors, drives,
sensors, pumps, valves, I/O — which neither of them has a single glyph for.

## Rebuilding

```bash
tools/icons/build.sh
```

That creates a Python venv under `.dart_tool/icon-venv` the first time, then:

1. restores `TfcIcons.base.ttf` over `assets/fonts/TfcIcons.ttf`,
2. draws the glyphs in `industrial_icons.py` and merges them in,
3. regenerates `lib/converter/industrial_icons.dart` from the same list,
4. renders `proof_sheet.png` — the labelled contact sheet.

**Look at the proof sheet before you commit.** Every glyph appears there at
104px and at the sizes it is used at on a page (48, 24, 16). A glyph that
resolves at 104 and turns to mush at 24 is not finished; several in the set
went through three or four passes on exactly that.

`test/widgets/industrial_icons_golden_test.dart` is the durable check — it
renders every glyph from the font, so a dropped glyph or a shifted code point
fails CI instead of showing up as a tofu box on a live mimic.

## Why the font is built here and not on fontello.com

The original eight glyphs were generated by Fontello and checked in with no
sources, so adding a ninth meant re-uploading the set to a web service and
hoping the existing code points came back unchanged. They are code points that
live in saved pages: `U+E800` is the Baader logo on a real station's mimic.

So the build merges into the existing font rather than regenerating it, and
`merge_into_font` refuses outright to write over a code point that is already
taken. The eight Fontello outlines are copied through byte for byte; the test
above pins that too.

## Adding a glyph

1. Draw it in `industrial_icons.py`. The design space is documented at the top
   of `icon_builder.py`: a 1000x1000 square, origin top-left, **y pointing
   down**, artwork inside a 60-unit margin, `STROKE` (72) for main strokes.
   Compose with `rect`/`circle`/`stroke`/`fill`/`gear`/`din_module`, and
   `Ink().add(...)`/`.sub(...)`; winding is sorted out for you.
2. Append it to `GLYPHS` — **append**, never insert. Code points are allocated
   from `FIRST_CODE_POINT` in list order, so inserting one silently changes the
   artwork of every glyph after it on every page that already uses one.
3. Bump the matching count in `GROUPS`, which is what sections the picker.
4. `tools/icons/build.sh`, look at the proof sheet, then
   `scripts/goldens.sh --update test/widgets/industrial_icons_golden_test.dart`.
